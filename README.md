# Java Learning

Учебный репозиторий, в котором я осваиваю основы Java
в рамках перехода из manual QA в автоматизацию тестирования.

## Что здесь есть

- **Main.java** — первые программы: вывод в консоль,
  переменные, арифметические операции.
- **FizzBuzz.java** — циклы и условия: задача FizzBuzz,
  проверка чётности, подсчёт суммы (паттерн «накопитель»).
- **Student.java**, **Book.java** — классы с полями,
  конструкторами и методами.
- **Car.java** / **Garage.java** — практика ООП:
  инкапсуляция, массив объектов, обработка в цикле.

## Изученные темы

### Основы языка
- Синтаксис, переменные и типы данных (`int`, `String`, `boolean`)
- Арифметические операции, оператор остатка `%`
- Условия: `if / else if / else`, логические операторы (`&&`)
- Циклы `for`, `for-each`
- Массивы, паттерн «накопитель» (счётчик)

### Методы
- Объявление и вызов методов с параметрами
- Методы с возвращаемым значением (`return`, `boolean`)

### ООП
- Классы и объекты, поля
- Конструкторы, ключевое слово `this`
- Методы внутри класса
- Массивы объектов и их обработка в цикле
- Инкапсуляция: `private`, геттеры и сеттеры с проверкой данных

### Коллекции
- ArrayList: добавление (`add`), перебор, `size`, `contains`, `get`
